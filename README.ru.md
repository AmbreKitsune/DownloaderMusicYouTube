# Описание 😼

**DownloaderMusicYouTube** — небольшое консольное приложение на Python. Оно получает ссылку на YouTube или YouTube Music, скачивает доступную аудиодорожку и преобразует её в **MP3**. Проект рассчитан на простой сценарий: открыть терминал, передать ссылку и получить аудиофайл без отдельного графического интерфейса.

Изначально это был скрипт с ручным вводом URL. В обновлённой версии для командной строки используется **Typer**, для сообщений в консоли — **Rich**, а **FFmpeg** подготавливается автоматически. Само скачивание выполняется через **yt-dlp**.

В версии **v0.2.0** уже доступны самостоятельный **`music.exe`** и **установщик Windows**. Установщик добавляет директорию приложения в пользовательский `PATH`, поэтому запускать загрузку можно из любой папки через новый терминал — Python устанавливать не требуется. После успешной загрузки приложение автоматически открывает папку `downloads/`.

# Возможности 🛠️

- Скачивание аудио по поддерживаемым ссылкам **YouTube** и **YouTube Music**.
- Конвертация загруженного аудио в **MP3** через FFmpeg.
- Запрос кодирования MP3 с битрейтом **192 кбит/с** (качество исходника от этого не повышается).
- Запуск загрузки через параметр `--download <URL>`.
- Справка по команде `--help`.
- Автоматическое скачивание и распаковка FFmpeg при отсутствии локальных бинарников.
- Повторное использование уже скачанного FFmpeg.
- Работа с локальным FFmpeg без изменения системного `PATH`.
- Англоязычные сообщения о состоянии программы и ошибках; при обработанной ошибке скачивания возвращается ненулевой код завершения.
- Установка через Windows Setup с добавлением `music.exe` в пользовательский `PATH`.
- Работа самостоятельного `.exe` без установленного Python.
- Сохранение MP3 рядом с приложением и автоматическое открытие папки после успешной загрузки.

**Текущий объём функций:** загрузка аудио по ссылке в MP3. Плейлисты, пакетная загрузка и другие форматы пока не заявлены как проверенные возможности.

# Как это работает ⚙️

1. CLI получает URL через параметр `--download`.
2. Программа проверяет наличие `ffmpeg.exe` и `ffprobe.exe` в папке `ffmpeg/` **рядом с приложением**.
3. Если одного из бинарников нет, скачивается архив FFmpeg Essentials с **Gyan.dev**. Нужные файлы извлекаются, временные удаляются.
4. **yt-dlp** загружает доступное аудио, а локальный **FFmpeg** конвертирует его в MP3.
5. Готовый MP3 сохраняется в `downloads/` **рядом с `music.exe`**, после чего Windows открывает эту папку в Проводнике.

При запуске из исходников приложение лежит в `src/`, поэтому `ffmpeg/` и `downloads/` создаются **внутри `src/`**. Расположение песен не зависит от рабочей директории терминала.

FFmpeg загружается только при первом запуске (или если необходимых файлов нет). Глобально в Windows он не устанавливается.

# Быстрый старт 👾

## Требования

- **Windows 10/11**.
- Интернет для YouTube и первого скачивания FFmpeg.
- Свободное место для временного архива FFmpeg, распаковки и музыкальных файлов.
- **Python 3.12+ нужен только для запуска исходников.** Для установщика и готового `music.exe` он **не требуется**.

## Рекомендуется: Windows Installer 📦

1. Открой [последний релиз](https://github.com/AmbreKitsune/DownloaderMusicYouTube/releases/latest).
2. Скачай **`DownloaderMusicYouTube-Setup.exe`** и запусти его.
3. Выбери директорию установки (по умолчанию `%LOCALAPPDATA%\Programs\DownloaderMusicYouTube`). При стандартной установке для текущего пользователя права администратора не нужны.
4. После установки **открой новый терминал**, чтобы применился обновлённый пользовательский `PATH`.
5. Запусти загрузку:

   ```powershell
   music.exe --download "https://www.youtube.com/watch?v=VIDEO_ID"
   ```

Установщик размещает `music.exe`. При первом запуске программа сама подготовит локальный FFmpeg. Готовые MP3 появятся в папке `downloads/` внутри директории установки, а Проводник откроет её после успешной загрузки.

## Альтернатива: отдельный EXE 💻

1. Скачай **`music.exe`** со страницы [последнего релиза](https://github.com/AmbreKitsune/DownloaderMusicYouTube/releases/latest).
2. Перемести его в **папку с правами на запись**, например `D:\MusicDownloader`.
3. Открой терминал в этой папке и выполни:

   ```powershell
   .\music.exe --download "https://music.youtube.com/watch?v=VIDEO_ID"
   ```

Отдельный EXE не требует Python, но **не добавляет себя в `PATH`**. Вызывай его по пути или используй установщик для глобальной команды. Рядом с файлом автоматически создаются `ffmpeg/` и `downloads/`.

## Альтернатива: запуск исходников 🐍

1. Клонируй репозиторий:

   ```powershell
   git clone https://github.com/AmbreKitsune/DownloaderMusicYouTube.git
   cd DownloaderMusicYouTube
   ```

2. Создай виртуальное окружение и установи зависимости из `requirements.txt`:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. Запусти программу из корня репозитория:

   ```powershell
   .\.venv\Scripts\python.exe src/main.py --download "https://www.youtube.com/watch?v=VIDEO_ID"
   ```

При запуске исходников FFmpeg и песни сохраняются в `src/ffmpeg/` и `src/downloads/`.

## Первый запуск

- Если FFmpeg ещё нет, программа автоматически скачает и распакует необходимые Windows-бинарники.
- Первый запуск может занять несколько минут. При повторном используются уже существующие файлы.
- После успешной конвертации открывается папка с песней.

# Использование CLI 💻

**Справка (установленная версия):**

```powershell
music.exe --help
```

**Загрузка с YouTube:**

```powershell
music.exe --download "https://www.youtube.com/watch?v=VIDEO_ID"
```

**Загрузка с YouTube Music:**

```powershell
music.exe --download "https://music.youtube.com/watch?v=VIDEO_ID&si=SHARE_TOKEN"
```

**Запуск исходников (из корня репозитория):**

```powershell
python src/main.py --download "https://www.youtube.com/watch?v=VIDEO_ID"
```

**Всегда заключай полный URL в кавычки**, особенно при наличии `&` и других специальных символов оболочки. Параметр ссылки YouTube Music `si` вручную удалять не нужно, если вся ссылка передана в кавычках.

Запуск без аргументов выводит подсказку об `--help`, а `--download` без URL вызывает стандартную ошибку Typer. Для глобального вызова `music.exe` установи программу через **Setup** и открой новый терминал: отдельный EXE не регистрирует себя в `PATH`.

# Ошибки и их решение ❌

**`'music.exe' is not recognized`**  
Установи программу через **`DownloaderMusicYouTube-Setup.exe`** и открой **новый терминал**. Если скачан отдельный EXE, запусти его через полный путь или `.\music.exe` из папки с файлом.

**`No module named 'typer'`, `'rich'`, `'requests'` или `'yt_dlp'`**  
Это относится **только к запуску исходников**. Установи зависимости через `python -m pip install -r requirements.txt` в используемое окружение Python.

**`FFmpeg not found. Installing automatically...`**  
Ожидаемое сообщение при первом запуске. Дождись загрузки и распаковки.

**`Failed to download FFmpeg`**  
Проверь интернет и доступность источника [Gyan.dev](https://www.gyan.dev/ffmpeg/builds/), затем повтори попытку.

**`FFmpeg installation failed`**  
Проверь свободное место и права записи в папку приложения. Если установка прерывалась, проверь или удали неполные файлы в `ffmpeg/` перед повторным запуском.

**`Download failed: ...`**  
Ссылка может быть недоступна, ограничена или не поддерживаться. Возможно, YouTube изменил способы отдачи медиа. Проверь ссылку; при запуске исходников может помочь обновление `yt-dlp`.

**Предупреждение `No supported JavaScript runtime`**  
Некоторые версии `yt-dlp` могут выводить это предупреждение. Скачивание иногда продолжается, но набор доступных форматов бывает ограничен. Это не означает, что FFmpeg установлен неправильно.

**`Option '--download' requires an argument`**  
Укажи URL, например: `music.exe --download "https://www.youtube.com/watch?v=VIDEO_ID"`.

**Где мой MP3?**  
Смотри `downloads/` рядом с **`music.exe`** (установленная или отдельная версия) или `src/downloads/` (режим исходников). После успешной загрузки папка должна открываться автоматически.

# Вопросы и ответы ❓

**В: Нужен ли Python?**  
**О:** Нет, для установщика и готового `music.exe` он не нужен. Python требуется только для запуска исходников.

**В: Можно вызвать `music.exe` из любой папки?**  
**О:** Да, после установки через Setup и открытия нового терминала. Установщик добавляет папку программы в пользовательский `PATH`.

**В: FFmpeg устанавливается глобально в Windows?**  
**О:** Нет. Локальные `ffmpeg.exe` и `ffprobe.exe` хранятся рядом с программой внутри `ffmpeg/`.

**В: Где лежит скачанная музыка?**  
**О:** В `downloads/` рядом с `music.exe`. При работе из исходников — в `src/downloads/`.

**В: Папка с музыкой открывается автоматически?**  
**О:** Да, после успешного скачивания и конвертации MP3 в Windows.

**В: Работают ли ссылки YouTube Music?**  
**О:** Прямые ссылки на треки проверены. Если в URL есть `&`, заключай ссылку целиком в кавычки.

**В: MP3 будет без потери качества?**  
**О:** Нет. Программа кодирует доступное аудио в MP3 с запрошенным битрейтом 192 кбит/с. Утерянное в исходнике качество конвертация не восстановит.

**В: Есть графический интерфейс?**  
**О:** Нет. Это консольная Windows-утилита.

**В: Что происходит при удалении программы?**  
**О:** Установщик рассчитан на удаление приложения и его записи в `PATH` с сохранением папки `downloads/`. Перед ручным удалением папки установки лучше сохранить важную музыку отдельно.

# Ограничения 📢

- Текущая реализация и установщик **предназначены для Windows**.
- Автоматическая установка FFmpeg зависит от стороннего сервера и требует интернета при первом использовании.
- Изменения на YouTube или YouTube Music могут нарушать работу загрузчика.
- Некоторые видео недоступны из-за региональных ограничений, авторизации и правил платформы.
- Плейлисты, пакетная загрузка и форматы помимо MP3 не проверены для этого релиза.
- Имя файла формируется из названия ролика; одинаковые или нестандартные названия могут потребовать отдельной обработки.
- Для сохранения FFmpeg и музыки приложению нужны права записи рядом с `music.exe`. Не размещай отдельный EXE в защищённой папке.
- Предупреждение `yt-dlp` об отсутствии JavaScript runtime иногда ограничивает доступные форматы даже при успешной загрузке.
- Скачивай только материалы, на сохранение которых у тебя есть право, с учётом правил платформы и авторского права.
