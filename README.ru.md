# Описание 😼

**DownloaderMusicYouTube** — небольшое консольное приложение на Python. Оно получает ссылку на YouTube или YouTube Music, скачивает доступную аудиодорожку и преобразует её в **MP3**. Проект рассчитан на простой сценарий: открыть терминал, передать ссылку и получить аудиофайл без отдельного графического интерфейса.

Изначально это был скрипт с ручным вводом URL. В обновлённой версии для командной строки используется **Typer**, для сообщений в консоли — **Rich**, а **FFmpeg** подготавливается автоматически. Само скачивание выполняется через **yt-dlp**.

**Текущая версия запускается через Python.** Отдельный `music.exe`, установщик Windows, глобальная команда `music` и автоматическое открытие папки пока **запланированы, но не реализованы**.

# Возможности 🛠️

- Скачивание аудио по поддерживаемым ссылкам **YouTube** и **YouTube Music**.
- Конвертация загруженного аудио в **MP3** через FFmpeg.
- Запрос кодирования MP3 с битрейтом **192 кбит/с** (качество исходника от этого не повышается).
- Запуск загрузки через параметр `--download <URL>`.
- Справка по команде `--help`.
- Автоматическое скачивание и распаковка FFmpeg при отсутствии локальных бинарников.
- Повторное использование уже скачанного FFmpeg.
- Работа с локальным FFmpeg без изменения системного `PATH`.
- Англоязычные сообщения о состоянии программы и ошибках; при обработанной ошибке скачивания возвращается ненулевой код завершения.

**Текущий объём функций:** загрузка аудио по ссылке в MP3. Плейлисты, пакетная загрузка и другие форматы пока не заявлены как проверенные возможности.

# Как это работает ⚙️

1. CLI получает ссылку через `--download`.
2. Программа проверяет наличие `ffmpeg.exe` и `ffprobe.exe` в папке проекта `ffmpeg/`.
3. Если одного из файлов нет, скачивается архив FFmpeg Essentials с **Gyan.dev**. Программа извлекает нужные бинарники и удаляет временные файлы.
4. `yt-dlp` получает аудиопоток и передаёт его локальному FFmpeg для преобразования в MP3.
5. Готовый файл сохраняется в `downloads/` относительно **директории, из которой запущена команда**.

Для первоначальной установки FFmpeg нужен интернет. Она может занять несколько минут. Системная установка FFmpeg не требуется.

# Быстрый старт 👾

## Требования

- Windows 10/11.
- **Python 3.12 или новее** с доступом из терминала.
- Интернет для работы с YouTube и первой загрузки FFmpeg.
- Git — необязательно, только для клонирования репозитория.
- Свободное место для ZIP-архива FFmpeg, распаковки и музыкальных файлов.

**Устанавливать FFmpeg вручную и прописывать его в `PATH` не нужно.**

## Установка

1. Скачай архив проекта или клонируй репозиторий:

   ```powershell
   git clone https://github.com/AmbreKitsune/DownloaderMusicYouTube.git
   cd DownloaderMusicYouTube
   ```

2. Создай виртуальное окружение:

   ```powershell
   python -m venv .venv
   ```

3. Установи зависимости Python:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install yt-dlp typer rich requests
   ```

   **Важно:** в старом `requirements.txt` репозитория указан только `yt_dlp`. Перед использованием `pip install -r requirements.txt` обнови файл, добавив `typer`, `rich` и `requests`.

4. Запусти загрузку:

   ```powershell
   .\.venv\Scripts\python.exe main.py --download "https://www.youtube.com/watch?v=VIDEO_ID"
   ```

5. Найди MP3 в папке `downloads/` относительно директории запуска команды.

## Первый запуск

- Если FFmpeg отсутствует, программа автоматически загрузит архив для Windows и подготовит `ffmpeg.exe` и `ffprobe.exe`.
- Первый запуск может быть заметно дольше последующих.
- При повторном запуске уже существующие бинарники используются повторно.

# Использование CLI 💻

**Справка:**

```powershell
python main.py --help
```

**Загрузка с YouTube:**

```powershell
python main.py --download "https://www.youtube.com/watch?v=VIDEO_ID"
```

**Загрузка с YouTube Music:**

```powershell
python main.py --download "https://music.youtube.com/watch?v=VIDEO_ID&si=SHARE_TOKEN"
```

**Заключай URL в кавычки**, особенно если в ссылке присутствуют `&` или другие специальные символы оболочки. `si` — параметр ссылки для распространения; при корректных кавычках вручную удалять его не требуется.

Запуск `python main.py` без параметров выводит подсказку про `--help`. Если указать `--download` без значения, Typer сообщает об отсутствии аргумента.

**Команда пока не глобальная:** сейчас удобнее запускать скрипт из папки проекта. Вариант `music.exe --download <URL>` будет доступен после реализации установщика.

# Файлы и пути 📁

| Путь | Назначение |
| --- | --- |
| `main.py` | Точка входа, интерфейс командной строки |
| `downloader.py` | Настройки yt-dlp и загрузка аудио |
| `ffmpeg.py` | Проверка, скачивание, распаковка и очистка FFmpeg |
| `ffmpeg/ffmpeg.exe` | Локальный конвертер, создаётся автоматически |
| `ffmpeg/ffprobe.exe` | Локальная утилита анализа медиа, создаётся автоматически |
| `ffmpeg-release-essentials.zip` | Временный архив, удаляется после штатной установки |
| `temp/` | Временная папка распаковки, удаляется после штатной установки |
| `downloads/` | Результаты загрузки MP3 (относительно текущей рабочей папки) |
| `assets/icon.ico` | Иконка для будущей сборки приложения |

**Важный нюанс:** папка `ffmpeg/` создаётся рядом с `ffmpeg.py`, но путь `downloads/` — **относительный**. Если запустить программу из другой директории, файлы попадут в `downloads/` именно этой директории. Постоянную пользовательскую папку для музыки добавим позже.

`.gitignore` исключает из новых коммитов FFmpeg, скачанную музыку, временные файлы, виртуальные окружения и результаты сборки. Уже отслеживаемые Git файлы он автоматически не удаляет.

# Ошибки и их решение ❌

**`No module named 'typer'`, `'rich'`, `'requests'` или `'yt_dlp'`**  
Установи все четыре зависимости в то окружение Python, из которого запускаешь программу. При наличии `.venv` используй Python из него.

**`FFmpeg not found. Installing automatically...`**  
Обычное сообщение при первом запуске. Дождись окончания скачивания и распаковки.

**`Failed to download FFmpeg`**  
Проверь интернет и доступность источника [Gyan.dev](https://www.gyan.dev/ffmpeg/builds/), затем попробуй ещё раз.

**`FFmpeg installation failed`**  
Проверь свободное место и права на запись. Если ошибка повторяется, закрой программу и посмотри, не остались ли повреждённые файлы в `ffmpeg/` или `temp/`.

**`Download failed: ...`**  
Ссылка может быть недоступна, ограничена или не поддерживаться. Иногда проблема возникает после изменений YouTube. Проверь ссылку и при необходимости обнови `yt-dlp`.

**Предупреждение `No supported JavaScript runtime`**  
В некоторых версиях `yt-dlp` возможно такое предупреждение. Загрузка может продолжиться, но набор доступных форматов бывает ограничен. Это не ошибка установки FFmpeg.

**`Option '--download' requires an argument`**  
После `--download` должна идти ссылка. Например: `python main.py --download "https://www.youtube.com/watch?v=VIDEO_ID"`.

**MP3 не появился рядом с `main.py`**  
Проверь `downloads/` относительно рабочей директории терминала. Она не всегда совпадает с местоположением скрипта.

# Вопросы и ответы ❓

**В: Программа устанавливает FFmpeg в систему?**  
**О:** Нет. `ffmpeg.exe` и `ffprobe.exe` сохраняются в папку проекта.

**В: Python обязательно нужен?**  
**О:** Сейчас да. Отдельный `.exe` и установщик появятся позже.

**В: Можно вызвать `music.exe` из любой папки?**  
**О:** Пока нет. Для этого планируются установщик и регистрация команды через `PATH`.

**В: YouTube Music поддерживается?**  
**О:** Прямые ссылки на треки уже успешно использовались. Ссылки с `&` передавай целиком в кавычках.

**В: MP3 будет без потери качества?**  
**О:** Нет. Программа конвертирует доступное аудио в MP3 с запрошенным битрейтом 192 кбит/с. Качество исходного потока при конвертации повысить нельзя.

**В: Папка с музыкой открывается автоматически?**  
**О:** Пока нет. Сейчас папку `downloads/` нужно открыть вручную.

**В: Есть графический интерфейс?**  
**О:** Нет. Это именно консольная утилита.

# Ограничения 📢

- Автоматическая подготовка FFmpeg пока **предназначена для Windows**.
- Загрузка FFmpeg зависит от доступности стороннего сервера.
- Изменения на YouTube и YouTube Music могут нарушать работу извлечения аудио.
- Некоторые видео недоступны из-за региона, возраста, необходимости авторизации и других ограничений сервиса.
- Плейлисты, пакетная загрузка и форматы помимо MP3 пока не проверены как функции текущего релиза.
- Имя файла формируется из названия ролика; совпадения имён и нестандартные символы могут потребовать дополнительной обработки.
- Глобальной команды, отдельного установщика, постоянной папки загрузок и автоматического открытия папки пока нет.
- Скачивай только материалы, на сохранение которых у тебя есть право, и учитывай правила платформы и авторского права.
